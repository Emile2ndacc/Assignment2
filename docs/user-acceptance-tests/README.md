# User acceptance test diagrams

Add your externally created user acceptance test diagrams to this folder as
PNG, JPG, JPEG, WEBP, or GIF images. Use a descriptive filename, such as
`student-hours-acceptance.png`.

When the report is exported, each image will be added to `docs/report.md` under
**User Acceptance Tests** and included in the PDF. You do not need to edit the
report manually; ask the Guide to build the report after adding your diagrams.
