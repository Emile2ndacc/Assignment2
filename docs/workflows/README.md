# External workflow

Place your externally created workflow diagram in this folder as a PNG, JPG,
JPEG, WEBP, or GIF image. Keep the descriptive filename, for example
`award-approval.png`.

When the report is exported, the image will be added to `docs/report.md` under
**Workflows** and included in the PDF, just like the wireframe images.
You do not need to edit `docs/report.md` by hand. Ask the Guide to build the
report after adding your image.
